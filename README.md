# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」の1ページ構成コーポレートサイトです。

## 概要

- 会社紹介（ミッション）、事業内容、実績、会社概要、採用情報、お問い合わせ、お知らせ欄で構成された静的サイトです。
- フレームワークは使用せず、HTML / CSS / JavaScript のみで実装しています。
- OSのライト/ダークモード設定に応じて配色が自動的に切り替わります。
- 掲載されている社名・実績・数値等はすべて架空のものです。

## ファイル構成

```
company-site/
├── index.html   # ページ本体
├── style.css    # スタイル一式
└── script.js    # トップページのスカイライン描画・スクロール演出
```

## ブラウザで開く手順

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をダブルクリックするか、ブラウザにドラッグ&ドロップして開きます。
   - Windowsの場合: エクスプローラーで `index.html` を右クリック →「プログラムから開く」→ 任意のブラウザを選択
   - ターミナルから開く場合（例）:
     ```bash
     # macOS
     open index.html

     # Windows (PowerShell)
     start index.html

     # Linux
     xdg-open index.html
     ```

インストールやビルド作業は不要です。`index.html` を開くだけで表示できます。
